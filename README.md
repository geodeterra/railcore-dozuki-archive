# RailCore build guides: unofficial archive of railcore.dozuki.com

This repository is an unofficial community mirror of the RailCore II and RailCore® Mini Kit
build guides that were published at <https://railcore.dozuki.com/>. It was captured on
2026-11-16 because the Dozuki site may be shut down.

Read it as a website: <https://geodeterra.github.io/railcore-dozuki-archive/>

Contents:

- `railcore-ii/`: 20 guides for the RailCore II 300 ZL kit.
- `railcore-mini-kit/`: 20 guides for the RailCore® Mini Kit.
- `items/`: 115 part and tool pages, each listing the guides that use the item.
- `assets/images/large/`: 800 px images shown in the pages; `assets/images/zoom/`: 1600 px copies linked from each image.
